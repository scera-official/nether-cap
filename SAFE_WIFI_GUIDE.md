# Safe Wi-Fi Security Checklist

This guide is for securing a home or lab network that you own or are authorised to administer.

## Router configuration

- Use WPA2-AES or WPA3-Personal when supported.
- Set a long, unique Wi-Fi passphrase.
- Change the router's administrator password from its default.
- Install firmware updates from the router manufacturer's official support page.
- Disable WPS if it is not needed.
- Use a guest network for visitors and untrusted smart devices.
- Review connected-device lists in the router's official administration interface.
- Remove unknown devices by changing the Wi-Fi passphrase and reconnecting only your own devices.
- Turn off remote administration unless there is a clear need for it.

## Device hygiene

- Keep phones, computers, and IoT devices updated.
- Remove devices and apps you no longer use.
- Do not reuse your Wi-Fi password on websites.
- Use multi-factor authentication for important online accounts.
- Avoid entering credentials into unexpected captive portals or unfamiliar network sign-in pages.

## Safe learning exercises

- Read your router's security settings without changing them.
- Record the security mode and firmware version.
- Compare the router's settings with the manufacturer's recommendations.
- Build a local dashboard that displays signal strength from your own device without disconnecting clients or imitating another access point.

## Do not

- Test networks without permission.
- Interrupt other people's connections.
- collect or store other people's passwords.
- Create deceptive sign-in pages or impersonate trusted access points.
- Publish other people's network identifiers or personal information.

If you find a weakness in a network you do not own, stop testing and notify its owner or administrator through an appropriate channel.
