# Contributing

Contributions that improve documentation, clarity, accessibility, and defensive learning are welcome.

## Good contributions

- Correcting factual documentation errors with reliable references
- Improving general ESP8266 USB/serial troubleshooting
- Adding safe home-router security guidance
- Adding non-disruptive sensor or signal-display project examples
- Improving accessibility, spelling, and navigation

## Out of scope

Do not submit code, binaries, or instructions that enable unauthorised access, wireless disruption, credential collection, deceptive access points, or evasion of network protections.

Do not submit third-party files unless their licence clearly permits redistribution.

## Before opening a pull request

1. Explain the purpose of the change.
2. Link reliable sources for technical claims.
3. Confirm that you have permission to contribute the material.
4. Remove credentials, personal data, and private network details.
5. Keep the change focused and easy to review.
