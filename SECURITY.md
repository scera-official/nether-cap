# Security Policy

This repository is documentation-only and does not distribute firmware or executable tools.

## Reporting an issue

If you discover a security or privacy issue in this repository's documentation or GitHub configuration, please avoid posting secrets or personal information in a public issue. Contact the repository maintainers through the private security-reporting options provided by GitHub, if enabled.

## Scope

Reports may include exposed credentials, accidentally published personal data, malicious links, or materially unsafe technical claims.

This repository does not accept requests to add exploit code, wireless-disruption features, credential-capture workflows, or instructions for bypassing network protections.

## Responsible disclosure

Give maintainers a reasonable opportunity to review and address a report before publicly sharing details that could put people or systems at risk.
